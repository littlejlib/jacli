Searching the whole filesystem for a dependency takes minutes and is not how to find one. Read the coordinates out of the pom or build file, then ask jacli directly: jacli api -T <groupId:artifactId:version> --name <what you are looking for>, or jacli tree -T <g:a:v> to see what the artifact contains. jacli resolves it from ~/.m2 or the gradle cache itself - there is nothing to locate, unzip or disassemble. If you truly need a filesystem search, scope it to a directory rather than to / or ~.
