You do not need to locate, extract or disassemble a jar - jacli reads it in place from coordinates that are already in the pom or build file. jacli api -T <groupId:artifactId:version> <Type> [<Type>...] for signatures and members; jacli api -T <g:a:v> --name <substr|a|b|c> to hunt by name; jacli tree -T <g:a:v> to see what is in it; jacli src -T <g:a:v> Type#member for a body or a string constant, which is real decompiled source and beats javap -c. It resolves the artifact from ~/.m2 or the gradle cache itself. Keep javap ONLY for javap -v: constant pool, annotation retention, raw bytecode.
